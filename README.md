# DyPortfolio

A dynamic personal portfolio and ATS-compliant resume builder built with React, TypeScript, Tailwind CSS, and Supabase.

## Features
- **Dynamic Resume Builder**: Tailor your resume content with role presets and custom checklists.
- **Single-Page PDF Generation**: Client-side ATS-friendly PDF export.
- **Dynamic Content & Certificates**: Manage credentials, languages, and hobbies without modifying code.
- **Download Telemetry**: Instant downloads with optional post-download visitor feedback modal.
- **Monochrome Design**: High-contrast black and white styling with light and dark mode.
